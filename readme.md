- React + TypeScript + Next.js 숙달
- 직접 코드를 작성하고 디버깅하며 판단 기준을 함양하는 것이 목표. AI는 과제 설계와 코드 리뷰에 사용
- 아주 작은 단위의 프로젝트 여러 개로 구성
- 각 프로젝트는 세부 숙달 목표에 해당하는 능력을 키우기 위한 목적에 충실하게 설계
- 리뷰는 지적 사항 + 수정 방법 + 예제 코드 + 관련 책 챕터를 함께 받고, 책을 찾아 읽으며 직접 고친다

[파일 구성]
- 세부 숙달 목표 / 리뷰 규칙 : claude.md
- 12주 과제 계획 / 진행 기록 : task.md
- 기술 서적 참고 위치 (주제별 색인) : books.md
- 코드 리뷰 결과 : 각 과제 폴더의 review.md

[기술 서적]
- 모던 자바스크립트 Deep Dive / 모던 리액트 Deep Dive / 한 입 크기로 잘라 먹는 리액트 / 한 입 크기로 잘라 먹는 Next.js / 타입스크립트 교과서
