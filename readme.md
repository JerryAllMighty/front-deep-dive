할 일 목록(Todo) 앱
- 백엔드 연결 없이 브라우저 안에서만 동작하는 걸로, 딱 리액트 상태 관리 감각만 잡는 게 목적
- 입력창에 할 일을 쓰고 추가 버튼(또는 엔터)을 누르면 목록에 새 항목이 생기고, 
각 항목 옆에는 완료 체크박스와 삭제 버튼이 있어서 체크하면 취소선이 그어지고 삭제 버튼을 누르면 목록에서 사라지고, 
목록이 비어있을 때는 "할 일이 없습니다" 같은 안내 문구가 보이게 만드는 거예요. 
여기에 욕심을 하나 더 내면, 완료된 항목만 보기/전체 보기 필터 토글을 추가해보는 것도 좋아요.

- 리액트 공식 문서(react.dev)가 최근 들어 굉장히 잘 정리돼 있어서, 여기서 useState, 렌더링, key 관련 페이지를 먼저 읽는 게 검색으로 파편화된 블로그 글보다 훨씬 정확
